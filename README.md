# OHC
ONE HIT CREW es una marca de cultura urbana, música y comunidad que conecta artistas, eventos, estilo, creatividad y movimiento. Nace como una plataforma para sumar talento, amplificar sonidos, crear experiencias y construir una crew que viva la cultura con identidad, energía y actitud. ONE HIT CREW no es solo un nombre: es un movimiento de sonidos
